    5. USB Audio, Bluetooth MIDI & Firmware Flashing

    Routing rules for DAW recording, external Bluetooth MIDI keyboards, and updating or restoring M-VAVE FM-1 hardware.

    Audio & MIDI Routing (GLO 4/4 & REC)

    • USB Audio Independence: The physical speaker/headphone amplifier level is controlled on GLO 4/4 → K4 (OUT LEVEL) (`AUTO 0dB`, `LINE -6dB`, `BOOST +3dB`) while USB Audio stays at full 44.1 kHz studio line level.
    • USB Synth + Drum Mix: HOME 3/3 balances global SYNTH LVL, KICK DUCK (sidechain compression depth), DUCK SRC (any of the 8 drum voices BD..RS), and DRM LVL.
    • Bluetooth MIDI (REC / GLO+HOME): Hold GLO + HOME to open the BLE scan/connect list for wireless keyboards or computers; toggle BT radio and routing (`PC + KYBD`, `KYBD HOST`, `PC DEVICE`, `OFF`) on GLO 4/4 → K3.
    • Hardware Combos & Easter Eggs: Press OCT- + OCT+ together for the STARFISH About App page & Chorusy Cmaj9 shimmer; hold HOME + SEL for A/B Patch Compare; press HOME + SAVE (or hold HOME 0.45s) for Live Memory Lock and 1-tap SAVE snap-back; hold GLO + ARP for Disco Starfish; hold ARP + OCT+/- for Arp Latch; hold REC + Knob/SELECT to adjust Synth Recording Bars (1–16).
    • SEQ Live Fills & Transitions: While playing, hold SEQ + Black Keys 1–8 (C#..F#2) for 1/32 multi-track drum rolls, SEQ + Black Key 9 (G#2) for a Riser build, and SEQ + Black Key 10 (A#2) for a Wash transition.
    • Channel Assignment: GLO 4/4 sets Synth RX/TX MIDI channel (K1: OMNI / 1–16) and Drum MIDI channel (K2: OFF / 1–16).

    Installing Firmware to FM-1 Hardware

    • Step 1 — Export & Build: Push the firmware source (from Export GitHub .zip or this repository) to GitHub. GitHub Actions automatically compiles starfish.fwsc and publishes Releases + GitHub Pages (index.html + guide.html).
    • Step 2 — Open Web Installer: Open the STARFISH Web MIDI Installer in Chrome or Edge with your FM-1 connected directly via a USB-C data cable.
    • Step 3 — Flash Safely: The page auto-loads starfish.fwsc (or lets you drop a downloaded .fwsc file). Confirm the backup prompt, press Install, and wait until the status reaches Done.
    • Recovery & Stock Return: The same Web Installer includes a verified stock M-VAVE firmware restore workflow and hardware crash-log reader.
